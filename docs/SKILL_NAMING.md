# 高教杯 Skills 命名说明

本项目面向中国高校数学建模竞赛场景，用户可见名称统一使用“高教杯”中文名称。

## 为什么文件夹和 `name` 仍然是英文

Codex 官方 skill 校验器要求 `SKILL.md` frontmatter 的 `name` 使用：

- 小写英文字母；
- 数字；
- 连字符；
- 最长 64 个字符。

因此，下面两类名称必须分开：

| 层级 | 用途 | 示例 |
|---|---|---|
| 机器标识 | 文件夹名、frontmatter `name`、`$skill` 调用 | `04-cumcm-modeling` |
| 用户名称 | agent 界面、README、阶段标题和说明 | 高教杯建模设计 |

这不是保留旧名称作为主名称，而是 Codex 的加载格式限制。用户界面和工作流说明以中文名称为准。

## 调用规则

在 Codex 中使用机器调用名，例如：

```text
$04-cumcm-modeling
$06-cumcm-result-mvp
$11-cumcm-verify
```

阅读项目文件、报告和界面时，使用上表中的中文名称。`CUMCM` 只作为历史兼容和内部技术标识，不改变本项目面向中国高教杯的定位。
