# 高教杯本地 Skills

本目录保存面向中国高校高教杯数学建模竞赛的新命名 skills。

## 命名规则

- 文件夹名和 `SKILL.md` frontmatter 的 `name`：使用 Codex 可识别的英文编号名；
- `agents/openai.yaml` 的 `display_name`：使用中文高教杯名称；
- 每个目录必须包含 `SKILL.md`、`agents/openai.yaml`、`references/` 和 `scripts/`；
- 不把旧全局 skill 名称作为本地主名称。

完整映射见 [docs/SKILL_NAMING.md](../docs/SKILL_NAMING.md)。
