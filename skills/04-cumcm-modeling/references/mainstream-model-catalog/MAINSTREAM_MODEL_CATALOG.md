# MAINSTREAM MODEL CATALOG

版本：MMC-2026-08-28-CLEAN1；来源：用户提供的主流模型表（已完成结构清洗）+ 少量低优先级补充。

本目录保留图片中的 86 个场景、全部首选/备选条目，并拆分模型、算法、求解器、检验、指标、预处理和仿真对象。图片条目约占目录主体 90%；补充方法统一标记 B/C 级，不得默认作为主模型。

## 选择顺序

人工锁定 → S 级 → A 级 → 数据/题意适配 → 验证与复现筛选 → 必要时 B/C 级（需说明理由；C 级需人工确认）。
