# 扫描论文 OCR 与安全替换流程

## 目标

用于处理已去除水印的扫描版优秀论文。目标是尽量提取可用于样例检索的标题、摘要、关键词、方法标签和简短总结，并在确认可读后替换原先不可读的源文件。

## 适用条件

使用本流程前应满足：

- 文件是扫描版 PDF 或图片版论文。
- 用户已确认文件无水印，或已自行去除水印后重新提供。
- 用户授权直接按图像版处理，不再逐篇询问。

不满足时，先走 `review-workflow.md` 中的“扫描件分流”。

## 推荐工具

- `pypdfium2`：将 PDF 页面渲染为图片。
- `rapidocr-onnxruntime`：对渲染页做 OCR。
- `pdfplumber` / `pypdf`：先尝试常规文本提取，判断是否确实需要 OCR。

如果 OCR 依赖缺失，可安装轻量 OCR 依赖；安装失败时，说明缺失依赖并停止批量替换。

## 处理步骤

1. 建立输出目录：
   - OCR 文本：`math-modeling-intake/_catalog/ocr/<year>/`
   - 首页预览：`math-modeling-intake/_catalog/ocr-preview/<year>/`
   - 替换报告：`math-modeling-intake/_catalog/<year>-replacement-report.md`
   - 原文件备份：`math-modeling-intake/_backup/<year>-before-readable-replace/`
   - 被占用待替换文件：`math-modeling-intake/_pending-replace/<year>/`

2. 对每篇 PDF：
   - 先用常规 PDF 文本提取判断是否已有文本层。
   - 若文本层为空或极弱，用 `pypdfium2` 渲染首页。
   - 对首页图片运行 OCR。
   - 保存 OCR 文本为 `<stem>.page1.txt`。
   - 保存首页预览为 `<stem>.page1.png`。

   对图片文件夹论文：
   - 按自然页序读取 `.jpg` / `.jpeg` / `.png`。
   - 默认先 OCR 前 1-3 页，形成结构化侧写 `<folder>.structure.txt`。
   - 若前几页能覆盖标题、摘要、关键词和主要问题路线，按结构化侧写建卡。
   - 若前几页不足以判断，可扩大到目录页或关键章节页；仍不可读时停止自动入库，不猜测标签。

3. 可读性判定：
   - OCR 文本长度足够。
   - 中文字符数量足够。
   - 包含论文结构标记，如“摘要”“关键词”“问题一”“模型”“本文”。
   - 能识别出标题、摘要级内容或主要建模方法。

4. 生成样例信息：
   - 标题：优先使用 OCR 首页识别标题；若标题识别失败，使用文件名。
   - 摘要：提取“摘要”到“关键词”或正文开头之间的内容，压缩为短总结。
   - 关键词：优先使用论文关键词；缺失时从标签和标题补充。
   - 标签：根据题型、方法、数据、结构和图表特征生成。
   - 文本状态标记为 `ocr-first-page`。
   - 备注写明“使用 OCR 首页文本生成标签和摘要；全文仍按图像版论文处理。”
   - 图片文件夹若通过结构化 OCR，文本状态标记为 `image-ocr-structure`。
   - 图片文件夹若未通过结构化 OCR，保留 `待人工复核`，并提示用户人工阅读、提供更清晰版本或放弃该样例。

5. 安全替换：
   - 只有通过可读性判定的文件才允许替换原源文件。
   - 替换前先备份当前目标文件。
   - 不可读文件不替换。
   - 如果目标文件被 PDF/WPS/预览进程占用，不能强制覆盖；将新文件复制到 `_pending-replace/<year>/`，并在报告中说明。

6. 刷新索引：
   - 重新生成 `math-modeling-intake/_catalog/sample-index.md`。
   - 重新生成对应年份的样例卡片。
   - 抽查至少一篇卡片，确认标题不是正文首句误判，标签不是全量兜底标签。

7. 整理后复核：
   - 检查 `math-modeling-intake/_catalog/manifest.json` 的样例总数、年份分布和文本状态。
   - 确认本轮处理对象不再处于 `scan-like`、`image-folder` 或 `待人工复核`，除非报告中明确列为不可读或等待用户决定。
   - 对图片文件夹论文，逐篇读取对应 `*-image-ocr-report-*.json`，确认 `readable=true` 后再接受 `image-ocr-structure` 入库结果。
   - 抽查本轮生成的 `.structure.txt`、样例卡片和 `sample-index.md`，确认标题、摘要、关键词和标签来自 OCR 内容而不是文件名兜底。
   - 若发现标题误判、乱码摘要、空关键词或兜底标签，扩大 OCR 页数或改为人工复核，不要把该样例标为已完成。

## 报告格式

替换报告使用表格：

```markdown
# <year> 去水印论文替换报告

| 文件 | 页数 | OCR 可读 | 已替换 | 说明 |
|---|---:|---|---|---|
| A023.pdf | 45 | 是 | 否 | OCR 首页清晰；目标文件被 PDF/WPS 进程占用，未覆盖。待替换文件已放入 `_pending-replace/<year>/A023.pdf`。 |
```

## 文件锁处理

Windows 上 PDF 预览器、WPS、浏览器或系统预览进程可能占用目标 PDF。

处理规则：

- 不杀进程，除非用户明确要求。
- 不删除或强制移动被占用文件。
- 将新文件放入 `_pending-replace/<year>/`。
- 在报告中列出“可读但未覆盖”的文件。
- 等用户关闭占用程序后，再补做替换。

## 质量边界

OCR 首页足以用于标签、摘要级总结和样例检索，但不等于全文可编辑文本。全文审阅仍按图像版论文处理，需要逐页渲染或 OCR 相关页面。

图片文件夹前 1-3 页 OCR 足以用于结构化标签、摘要级总结和样例匹配，但不等于全文可检索。若后续审稿需要引用具体图表、章节或段落，应再按页 OCR 或视觉检查相关页。

不可将 OCR 误识别内容当作确定事实；发现乱码、错字或明显误识别时，保守标注 `待人工复核`。
