# 输入文件夹结构规则

## 目标

支持用户直接提供一个总文件夹，内部按“题目”和“优秀论文”分层组织。技能应先解析目录，再决定读取哪些文件、如何建索引、如何打标签。

## 期望结构

```text
总文件夹/
├── 题目/
│   └── 年份/
│       ├── A/
│       │   ├── 题目.docx
│       │   ├── 题目.pdf
│       │   └── format/
│       ├── B/
│       ├── C/
│       └── D/
└── 优秀论文/
    └── 年份/
        ├── paper-1.pdf
        ├── paper-2/
        │   ├── 1.jpg
        │   ├── 2.jpg
        │   └── ...
        └── ...
```

## 读取规则

- `format` 必读。
- 同一题目的多个题目文件只选一个可读文件读取即可。
- 题目文件按年份、题号归类，不进入样例索引。
- 优秀论文按年份归类入库。
- `jpg` 文件夹视为图像版论文，按文件顺序或页码顺序读取。

## 整理规则

整理时为每个对象生成最小必要元数据：

- 年份
- 题号或来源
- 文件路径
- 类型（题目 / 优秀论文 / 图像版论文）
- 标签
- 简短总结
- 关键词

## 处理优先级

1. 评分标准 `format`
2. 题目文件
3. 优秀论文 PDF
4. 优秀论文图片文件夹
5. 外部权威参考资料
