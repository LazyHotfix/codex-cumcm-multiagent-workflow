# 结构化国赛论文分节蓝图

本文件只提供“如何组织论证”的蓝图，不规定具体模型。使用时先依据题目动作选择一种或组合多种蓝图，再用真实结果填充。

## 共同规则

每道题的顺序优先保持：

```text
总起段 → 问题分析 → 数据/指标处理 → 模型建立 → 求解或检验 → 结果解释 → 小结
```

若某一步不适用，删除该步，不保留空标题。每个小节至少回答一个“为什么、怎么做、得到什么”中的问题。

## 小节写作节奏

- 二级标题开头用一至两句说明本节任务，不机械重复“本小节”。
- 公式出现前先解释建模对象，公式后解释符号和业务含义。
- 图表出现前说明它要验证什么，出现后只解释与题目相关的主要现象。
- 小结只保留直接结论、关键数值和决策含义，不重复算法流程或全部稳健性参数。
