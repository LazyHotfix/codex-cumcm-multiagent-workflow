# G2 结果确认门

进入：06-cumcm-result-mvp 已完成 MVP 和 result_ai_review，所有纳入问题的三层状态通过。

必须向用户展示：

- 每个问题的 MVP；
- 核心数字和单位；
- 实现一致性结论；
- 本题合理性结论；
- 验证证据；
- 异常和限制；
- 将进入论文的图表与结论。

只有用户明确确认结果范围、关键数字、异常解释、限制并允许进入写作，才可继续。

到达本门必须停止当前轮次，不得调用 07-cumcm-drawio、08-cumcm-template 或 09-cumcm-writing。

结果、代码、数据口径或核心数字变化时，旧 G2 立即失效，必须重新运行受影响结果和本阶段。
